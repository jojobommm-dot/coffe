# Fastcup — сайт сети кофейных автоматов в Перми

Инструкции для Claude Code. Читай этот файл перед любой задачей.

## Общение
- Отвечай на русском, простыми словами: владелец сайта не программист.
- Перед большими изменениями (больше 2–3 файлов или переделка блока) коротко опиши план и дождись «ок».
- После правок скажи, что изменилось и как проверить.

## О проекте
Статический одностраничный сайт: HTML + CSS + JS, без сборки, без npm, без фреймворков. Не добавляй сборщики и библиотеки без явной просьбы.

```
index.html          вся страница (SEO-метатеги, JSON-LD schema.org, блоки, FAQ)
css/style.css       стили; цвета и шрифты — переменные в :root в начале файла
js/config.js        контакты, адрес формы заявок
js/points.js        точки автоматов на карте (сейчас ПРИМЕРЫ адресов)
js/main.js          карта первого экрана (метки, ближайшая точка), геолокация, «Маршрут пешком», эффект зёрен, форма
js/omap.js          движок офлайн-карты для сайта и приложения (перетаскивание, зум, плитки, метки, маршрут); стили — css/omap.css
js/map-data.js      границы офлайн-карты — создаётся tools/build_map.py, руками не править
js/beans-data.js    картинка зёрен в base64 (большой файл — не читай целиком без нужды)
images/             исходники в полном размере — НЕ изменять и не удалять
images/web/         сжатые версии для сайта — на странице используются только они
images/web/map/     офлайн-карта Перми: картинки WebP {уровень}/{x}-{y}.webp — создаются tools/build_map.py, руками не править
tools/build_routes.py  граф пеших дорог для app/: `python tools/build_routes.py --refresh` (нужен shapely)
tools/build_map.py  рисует карту из OpenStreetMap: `python tools/build_map.py --refresh` (нужны shapely и playwright, рендерит Chrome)
app/                приложение (PWA): index.html, app.js, app.css, route-worker.js (маршрут в фоне),
                    sw.js (офлайн), manifest.webmanifest, icons/, data/walk-graph.bin (граф — руками не править)
robots.txt, sitemap.xml
```

## Приложение (app/)
- Общие с сайтом файлы (points.js, map-data.js, omap.js, omap.css, картинки карты) подключаются через `../`.
- Изменил что-то, что сохраняется на телефоне (карту, граф, файлы app/), — увеличь `VERSION` в `app/sw.js`.
- Плавность проверяй замером кадров: у владельца слабая видеокарта.

## Как проверить сайт
```
python -m http.server 8000
```
Открыть http://localhost:8000. Геолокация работает только на localhost или https.

## Правила для кода
- Контакты и настройки — только в `js/config.js`; точки — только в `js/points.js`. Не хардкодь их в HTML/JS.
- Цвета и шрифты бери из CSS-переменных в `:root`, новые — добавляй туда же.
- Сайт должен хорошо выглядеть на телефоне (ширина от 360px) — проверяй мобильную вёрстку.
- У каждой картинки должен быть осмысленный `alt` на русском.
- Сохраняй SEO: title, description, Open Graph, JSON-LD. Меняешь цены/меню на странице — обнови их и в JSON-LD.
- Домен пока `https://example.ru` — при замене менять в `index.html`, `robots.txt`, `sitemap.xml` одновременно.
- Не выдумывай отзывы, адреса, цены и факты о компании. Если данных нет — спроси.

## Картинки
- Исходники лежат в `images/` (некоторые по 8–9 МБ) — не трогай их, работай с копиями.
- Готовые для сайта картинки клади в `images/web/`: основной формат WebP, JPG как запасной через `<picture>`.
- Ориентиры по весу: фон/баннер до 200 КБ, обычные фото до 120 КБ, иконки до 30 КБ. Ширина баннера ~1920px, карточек ~800px.
- Инструмент: ImageMagick (`magick`). Пример: `magick images/cup.jpg -resize 800x -quality 80 images/web/cup.webp`.
- После добавления картинки проверь, что путь в HTML/CSS верный.
