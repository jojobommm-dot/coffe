# Сайт Fastcup

Обычный статический сайт: HTML, CSS и JS без сборки. Откройте `index.html` в браузере. Карта и геолокация заработают после шагов ниже.

## Структура

```
index.html            страница
css/style.css         стили (цвета и шрифты заданы в :root вверху файла)
js/config.js          ← телефон, Telegram, Max, адрес для заявок
js/points.js          ← ваши точки на карте (сейчас там ПРИМЕРЫ)
js/main.js            карта первого экрана, геолокация, зёрна, форма
js/omap.js            движок офлайн-карты (общий для сайта и приложения), стили — css/omap.css
js/map-data.js        границы офлайн-карты (создаётся tools/build_map.py)
js/beans-data.js      картинка зёрен для эффекта (встроена в файл, чтобы работала и без сервера)
images/               ваши исходники (не изменены)
images/web/           сжатые версии для сайта + новые картинки
images/web/map/       офлайн-карта Перми: готовые картинки WebP на 4 уровня масштаба (создаются tools/build_map.py)
tools/build_map.py    рисует карту из данных OpenStreetMap
tools/build_routes.py собирает граф пеших дорог для маршрутов в приложении
app/                  приложение «Fastcup — кофе рядом» (PWA), см. раздел ниже
```

## Что сделать перед запуском

1. **Точки.** Замените примеры в `js/points.js` на реальные адреса и координаты. Карта сама подстроит масштаб под все точки.
2. **Контакты.** Телефон, Telegram, Max и email в `js/config.js`.
3. **Форма заявок.** Пока заявка открывается письмом на email. Чтобы заявки приходили в Telegram, нужен маленький обработчик (Яндекс Cloud Function, PHP-скрипт на хостинге или Formspree). Его адрес вставьте в `formEndpoint`: сайт отправит туда JSON `{name, phone, topic, message}`.
4. **HTTPS.** Браузеры показывают местоположение только на сайтах с `https://` (или на `localhost`). Если открыть файл двойным кликом, геолокация может не сработать. Для проверки запустите в папке `python -m http.server` и откройте http://localhost:8000.

## Как правильно запустить «по-современному»

- **Хостинг:** для статического сайта хватит любого: Яндекс Object Storage + CDN, Timeweb, Beget, REG.RU. Домен вида `fastcup.ru` и бесплатный SSL (Let's Encrypt) обычно включаются в панели.
- **Яндекс Бизнес:** добавьте каждую точку в Яндекс Бизнес (yandex.ru/sprav). Тогда автоматы появятся в поиске Яндекс Карт, а люди смогут оставлять отзывы.
- **Аналитика:** подключите Яндекс Метрику и поставьте цели на кнопки «Арендовать аппарат», «Запросить прайс» и на отправку формы.
- **Персональные данные:** для формы нужна страница «Политика обработки персональных данных» (152-ФЗ). Добавьте её и сделайте ссылкой текст под кнопкой.
- **Дальше по росту:** когда точек станет много, держите их в Google/Яндекс Таблице или в небольшой админке. Тогда сайт подтянет их сам, и править код не придётся.

## Карта

Карта своя, офлайн: ни ключей, ни внешних сервисов. Её рисует скрипт `tools/build_map.py` из открытых данных OpenStreetMap (подпись «© участники OpenStreetMap» на карте обязательна по их лицензии).

- Карта охватывает весь Пермский городской округ. Дальше его границ карту не сдвинуть, граница города нарисована пунктиром.
- Карта заранее нарисована картинками (`images/web/map/`) на 4 уровня масштаба, как у Яндекса: браузер грузит только видимые куски нужного уровня и подгружает остальные, когда карту двигают. Готовые картинки двигаются плавно даже на слабых ноутбуках.
- На компьютере карту двигают мышкой, масштаб — кнопками «+» и «−». Колесо мыши листает страницу, а не карту.
- На телефоне одним пальцем листается страница, двумя пальцами карта двигается и масштабируется.

Пересобрать карту (например, обновить улицы через год): `pip install shapely playwright`, затем `python tools/build_map.py --refresh`. Картинки рендерит установленный Google Chrome.

## Приложение (app/)

Отдельная страница `сайт/app/`, которую можно установить на телефон как приложение (PWA). На сайте в карточке ближайшей точки есть ссылка «Маршрут в приложении».

- Показывает, где вы (синяя точка и круг точности GPS), и строит **пеший маршрут** до ближайшего автомата прямо на нашей карте: расстояние и время пешком. Ближайшая точка выбирается по настоящему пешему пути, а не по прямой.
- «Другая точка» и нажатие на метку — маршрут до другого автомата. Кнопка с прицелом — следовать за вами.
- Если геопозиция недоступна или вы не в Перми — нажмите на карту, чтобы выбрать, откуда идти.
- **Работает без интернета.** Маршрут считается на самом телефоне по графу пеших дорог Перми (`app/data/walk-graph.bin`, ≈ 2,6 МБ: улицы, тротуары, дорожки, лестницы из OpenStreetMap). При первом открытии приложение сохраняет на телефоне себя, карту и граф (≈ 6 МБ).
- Установка: на Android/в Chrome — кнопка «Установить» в приложении; на iPhone — «Поделиться» → «На экран Домой». Для установки и геопозиции сайт должен открываться по `https://`.

Обновления:
- Новые точки из `js/points.js` подхватываются сами (при следующем запуске приложения).
- Пересобрали карту или граф дорог — увеличьте `VERSION` в `app/sw.js`, иначе у установивших останется старая версия.
- Обновить граф пеших дорог: `python tools/build_routes.py --refresh` (нужен shapely).

## Как работает «Маршрут пешком»

1. Если посетитель разрешил геолокацию, сайт считает расстояние по прямой от него до каждой точки из `points.js` и сортирует их: ближайшая первой.
2. В карточке слева показывается ближайшая точка, её адрес и расстояние. Ссылка «Маршрут пешком» открывает Яндекс Карты с готовым пешим маршрутом: от посетителя до этой точки.
3. Кнопка «Другая точка» переключает на следующую по удалённости. Клик по метке на карте тоже выбирает эту точку, и маршрут строится уже до неё.
4. Если геолокацию не разрешили, маршрут строится до выбранной точки, а начало Яндекс Карты подставят сами по местоположению телефона.

## SEO: что уже сделано и что сделать вам

Уже в коде:
- title и description под запросы «кофе с собой Пермь», «кофейный автомат Пермь», «аренда кофейного автомата», «ингредиенты для кофемашин оптом»;
- гео-метатеги для Перми, Open Graph для красивых ссылок в мессенджерах;
- микроразметка schema.org (JSON-LD): организация, кофейня с меню и ценами, FAQ. Яндекс показывает её в расширенных сниппетах;
- блок «Частые вопросы» (его любят и люди, и поисковики), alt-тексты у картинок, `robots.txt` и `sitemap.xml`.

Сделайте сами:
1. Замените `https://example.ru` на свой домен в `index.html`, `robots.txt` и `sitemap.xml`.
2. Добавьте сайт в **Яндекс Вебмастер**, подтвердите права (метатег уже подготовлен в `index.html`), загрузите sitemap.
3. Заведите каждую точку в **Яндекс Бизнесе** со ссылкой на сайт. Для локального поиска это важнее всего.
4. Подключите **Яндекс Метрику**.
5. Собирайте отзывы в карточках Яндекс Бизнеса. Не публикуйте на сайте выдуманные отзывы: это вредит доверию и нарушает закон о рекламе.

## Шрифты

Caveat (рукописный, с кириллицей) для заголовков и Inter для текста подключены через Google Fonts. Если хотите, чтобы сайт не зависел от Google, скачайте их на fonts.google.com, положите в папку `fonts/` и подключите через `@font-face`.
